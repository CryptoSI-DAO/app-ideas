# Balletcore — Score: 7.8/10

## Overview
**Purpose**: Mobile reference guide for the Balletcore fashion aesthetic and style inspiration
**Score**: 7.8/10

## Core Features
- Curated gallery of balletcore outfits and styling inspiration
- Filter by occasion (casual, formal, streetwear)
- Shop-the-look links to popular retailers
- Seasonal trend forecasts
- User style diary and moodboard

## Technical Requirements
- React Native for iOS/Android
- Image-heavy UI with lazy loading
- Local JSON for styling tips and guides
- Web API integration for retailer links
- Offline access to saved looks

## Monetization
- Free core app with basic gallery
- Premium tier ($4.99/month) for:
  - Exclusive editorials and interviews
  - Personalized style recommendations
  - Early access to new content
- Affiliate links to retailers (no ads)
