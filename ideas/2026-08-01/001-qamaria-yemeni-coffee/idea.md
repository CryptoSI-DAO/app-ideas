# Qamaria Yemeni Coffee

**Date**: 2026-08-01
**Category**: Reference
**Score**: 7.4/10

## Core Problem

Qamaria Yemeni Coffee is experiencing explosive growth, but users have no dedicated mobile solution to track, learn, and manage this growing interest in authentic Yemeni coffee culture.

## Target Audience

Coffee enthusiasts seeking authentic Yemeni coffee information, recipes, sourcing guides, and community discussions.

## MVP Features

- Core reference database for Yemeni coffee varieties (Himyarite, Mocha, etc.)
- Brewing guides and recipes specific to Yemeni coffee beans
- Sourcing map showing legitimate Yemeni coffee producers
- Roast profile comparison tool
- User bookmarking and favorites system
- Community Q&A section
- Offline access to saved content

## Technology Stack

- **Frontend**: React Native / Flutter (cross-platform)
- **Backend**: Supabase (real-time database, auth)
- **Monetization**: Freemium with premium features ($4.99/year)
- **Distribution**: App Store & Google Play
